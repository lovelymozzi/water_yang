# 로딩 직후 UI 깜빡임: 실제 재현과 수정 검사

2026-11-15 사용자가 직접 브라우저 테스트와 반복 수정을 요청한 범위에서, 기존 Codex 내부 보기 탭의 `http://localhost:8080/web/?foam=short-films-20261113-2133`을 사용했다. 새 탭은 만들지 않았다.

## 재현한 증상과 원인

수정 전 두 번의 새로고침 재진입에서 같은 증상을 캡처했다. 첫 번째 캡처의 15번 프레임에서 하단 메뉴 배경의 그라데이션과 윗선이 사라지고, 17번 프레임에서 스타트 버튼 배경이 사라졌다. 아이콘과 글자는 남았다. 두 번째 캡처에서도 각각 14번과 16번 프레임에 같은 누락이 있었다.

두 요소는 모두 `border-image`를 합성된 PNG의 CSS background로 교체하는 경로다. PNG URL만 생성된 시점에 기존 그림을 제거하면, 디코드가 끝나지 않은 배경이 한 프레임 비어 보였다.

이전 커밋의 `Image.decode()` 보정이 실행 탭에 반영되지 않은 사실도 확인했다. 렌더러에 임시 진단 로그를 넣고 새로고침했을 때 해당 로그가 없었고, HTML import map으로 렌더러 모듈 URL에 새 버전을 지정하자 같은 탭에서 로그가 출력됐다. 그 뒤 디코드 후 교체 시점을 캡처했을 때 배경 누락이 사라졌다. 임시 진단 로그는 제거했다.

## 최종 수정

- 기존 `Image.decode()` 완료 뒤 교체하는 보정을 유지한다.
- `godot-shell.html`의 네이티브 import map이 모든 매니저의 렌더러 import를 동일한 버전 URL로 해석하게 한다. 수정 모듈이 캐시된 이전 모듈과 혼용되지 않는다. 렌더러 재수정 시 이 버전도 갱신한다.
- 씬 전체를 합성 PNG 준비까지 숨기는 대기는 제거했다. 이 대기는 커튼 없는 로비 진입을 약 1초 넘게 검게 만들었다. 사전 로딩한 기존 `border-image`를 표시하고, 새 이미지가 디코드된 뒤 교체한다. 폰트·효과 CSS 준비 대기는 유지한다.
- 반복 광택은 `2.9s linear infinite ui-shine-31_right`로 실제 동작 중임을 확인했다. 레이아웃·색·반복 광택·게임 규칙은 변경하지 않았다.

사용자가 앞서 승인한 “이번 오류 부분만 직접 수정”의 범위 안에서 renderer 보정을 수정했다. `renderer-decode.proposed.patch`는 이전 커밋 당시의 제안 기록이며, 그 파일의 씬 전체 대기 부분은 최종안에서 제거됐다.

## 실제 브라우저 검사 결과

최종 코드로 총 **995프레임 / 95.619초**를 순차 캡처했다.

| 상황 | 캡처 수 | 결과 |
| --- | ---: | --- |
| 새로고침 후 로비 진입 3회 | 150 + 140 + 140 | 배경 누락 0회 |
| 실제 스타트 버튼 → 인게임 | 130 | UI 배경 누락 0회 |
| 인게임 GiveUp → 로비 복귀 | 100 | 배경 누락 0회 |
| Shop 전환 → Home 복귀 | 55 + 100 | 배경 누락 0회 |
| 로비 대기·반복 광택 | 180 | 배경 누락 0회 |

실제 캡처는 약 10~11fps다. 60fps 전수 검사가 아니므로 표본 사이의 모든 GPU 프레임까지 검증했다고 해석하지 않는다. 초기 스플래시·커튼·정상 등장 애니메이션은 정착 후의 누락 검사와 구분했다.

하단 배경 표본 영역의 평균 RGB 밝기는 수정 전 정상 약 135.85에서 누락 프레임에 117.73으로 떨어졌다. 최종 세 번의 재진입에서는 135.58~135.85를 유지했다. 스타트 버튼 윗테두리 표본은 수정 전 누락 시 107.41, 최종 세 번에서는 206.71~209.28이었다. 이미지 방식 교체에 따른 작은 샘플링 차이는 남지만, 한 프레임 그림이 사라지는 변화는 나오지 않았다. 인게임 진입 후 정착된 하단 배경과 HUD의 표본은 각각 일정했다.

브라우저가 받은 HTML과 렌더러의 SHA-256을 디스크 파일과 대조해 일치함을 확인했다. 이미지 로드/디코드 오류는 없었다. 설정 메뉴를 통한 복귀 중 기존 `pop_Settings_1` 미배선 이벤트 경고가 별도로 기록됐다. 이 경고를 렌더 오류와 혼동하지 않았다.

실제 Start/GiveUp 검사로 로컬 하트가 5개에서 3개가 됐다. 고양이는 움직이지 않았고 진행 스테이지는 Level19를 유지했다.
