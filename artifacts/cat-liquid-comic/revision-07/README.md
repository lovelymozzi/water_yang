# 괴짜 연구자, 당사자 독백, next 전용 진행

2026-11-15. 사용자가 어린이 과학 도서 같은 그림체와 상황 설명을 지적해 8개 장면을 다시 그렸다. 앞선 만화 직접 적용 승인의 범위에서 StoryIntro 원본·계약·스토리 데이터·흐름을 함께 변경했다. Godot 게임플레이와 카메라는 수정하지 않았다.

## 그림과 독백

Sunburst 스킬의 `generate_image.py`로 high 편집 요청 2회를 실행했다. 첫 요청에는 기존 만화가 아닌 실제 게임의 `../game-style-reference.png`를 참조했다. 두 번째에는 새 첫 페이지와 실제 게임을 합친 참조 시트를 사용했다. 원화·프롬프트·요청별 generation JSON을 이 폴더에 보존했다.

갈색 펜선과 곱슬머리의 친절한 박사 대신, 비대칭 회색 머리·삐뚤어진 안경·구겨진 가운·짝짝이 양말·구부정한 자세의 괴짜 연구자로 변경했다. 고양이는 실제 게임의 긴 몸·반쯤 감긴 눈·초록/주황/파랑을 반영했다. 재질은 무광 면과 입체 명암 중심이다. 이는 새로 생성한 그림이며 실제 게임의 3D 메시를 렌더한 장면이나 픽셀 단위 동일성 검증 결과는 아니다.

장면별 문구는 모두 당사자의 독백이다. 1~6·8컷은 연구자, 7컷은 소파를 바라보는 고양이의 속말이다. 상황을 설명하는 서술자는 없다. 논문·학회에 집착하면서 노트를 계속 두고 오는 캐릭터로 묶었다. 실제 유변학 논문은 모티브이며, 등장 박사와 차원문은 허구다.

## 입력과 연결

표시되는 진행 글자는 `next` 하나다. `skip`, 타이핑 안내, 페이지 이동 안내를 제거했다. 대사창과 그림 영역에는 클릭 동작이 없다. `next`는 첫 컷이 나타난 뒤 항상 보이며, 타이핑 중에도 누르면 문장을 완성하는 중간 단계 없이 다음 컷으로 바로 넘어간다. 아무 입력 없이 다음 컷으로 자동 진행하지 않는다.

4번째 컷의 `next`는 FlowDriver 문서 엣지 `story.pageComplete`, 8번째 컷의 `next`는 완료 저장 후 `story.finish`를 발화한다. 전환 동안 현재 상태·rAF·진행 구독을 즉시 정리해 연타가 중복 전환이나 중복 저장을 만들지 않게 했다. 새 공개 API나 렌더러 내부 접근은 추가하지 않았다. 두 페이지의 `story-advance-01:click`, `story-advance-02:click` 이벤트를 next 버튼에서 사용한다. 분기는 첫 입장 1개와 페이지 문서 엣지 2개, 총 3개다.

seen 키와 `?story=replay`, 상점 배경, 4개 가로 컷의 누적 등장, 38ms 한글 음절 타이핑, 사선 프레임은 유지한다. 원화의 실제 흰 여백을 측정해서 8개 컷을 분리했다. 새 `story_cat_liquid_misfit_*` 에셋 경로와 CSS/JS `cat-liquid-v8`을 사용해 이전 캐시와 분리한다.

## 확인

생성 원화와 오프라인 배치 이미지를 파일로 열어 인물·고양이·가로 네 컷·프레임 잘림·독백 표시를 확인했다. `asset-check.json`은 컷 분리 좌표, 대사 폭/높이, 원화/에셋 해시를 기록한다. `two-page-board.jpg`, 페이지별 PNG와 `typewriter-preview.gif`는 Pillow 시안이며 실제 게임 화면 캡처가 아니다. GIF만 시연을 위해 자동 진행한다. 게임 시각 확인은 프로젝트 규칙에 따라 사용자에게 남긴다.

`node tests/story_intro_check.mjs`는 실제 FlowDriver와 렌더러/DOM 대역으로 next만 표시, 타이핑 중 next 즉시 진행, 대사창 무반응, 키보드, 두 문서 엣지, 이전 rAF 취소, 캐시 재입장, 마지막 연타 시 1회 저장, 첫 진입/재접속/다시보기, 분해된 한글 음절 출력을 확인한다. `splash_cache_check.mjs`, `ui_bare_asset_paths_check.mjs`와 함께 통과했다. localhost의 HTML/JS/CSS/데이터/흐름/계약/프레임/타격선 16개 응답이 작업 폴더와 일치한다. 기존 publish 보고서는 errors 0개/warnings 8개이며 이번 테스트 결과로 덮어쓰지 않았다.
