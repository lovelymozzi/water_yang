# 무문자 만화와 네 컷 스탬프 모션 — 세 번째 시안

2026-11-15. 사용자가 매끈한 3D 애니메이션풍을 지적하고 게임과 어울리는 만화체, 텍스트 없는 그림, 한 화면에 네 장이 순서대로 박히는 연출을 요청했다. “한화면에 순서대로 한장씩 탕탕탕 박히는 느낌”이라는 답변을 반영했다.

![순차 등장 모션 시안](stamp-preview.gif)

현재는 **원화와 오프라인 모션 시안**이다. 실제 게임 UI나 씬 흐름을 수정한 결과가 아니다.

## 표현

- 실제 게임의 고양이 얼굴·초록/파랑/주황 팔레트, 층층이 겹친 나무, 단순한 잔디·물의 형태를 참조했다. 이전 3D 생성 이미지는 이번 참조에 넣지 않았다.
- 선과 큰 색면, 절제한 셀 명암, 과장된 박사의 동작과 무심한 고양이 표정으로 바꿨다. 털 렌더·피사계 심도·매끈한 영화 조명을 사용하지 않도록 요청했다.
- 대사·내레이션·제목·컷 번호·효과음 글자·텍스트 버튼을 제거했다. 수첩 속 고양이/용기 그림과 색상 도식은 글 대신 쓰는 시각 단서다. 원화의 종이 소품에는 장식적 선이 있지만 읽을 수 있는 문구는 없다.
- 박사의 연구 → 차원문 사고 → 컵고양이·박스고양이와 만남 → 색상 반응 → 인간계 발견 → 모험 출발이라는 두 페이지/8컷의 줄거리는 유지한다.

## 한 화면에 네 컷이 등장하는 방식

| 컷 | 등장 시각 | 정착 시각 |
| --- | ---: | ---: |
| 첫 장 | 0.24초 | 0.44초 |
| 둘째 장 | 1.32초 | 1.52초 |
| 셋째 장 | 2.48초 | 2.68초 |
| 넷째 장 | 3.64초 | 3.84초 |

새 컷은 불투명하게 바로 등장하고 200ms 동안 1.16 → 0.96 → 1.015 → 1배로 눌리며 정착한다. 작은 회전과 위에서 내려오는 이동, 120ms의 짧은 타격선을 함께 사용한다. 이전 컷은 계속 남아 있고, 새 컷이 붙은 뒤 다시 숨기거나 움직이지 않는다. 화면 전체에 밝기 변화나 흔들림을 주지 않는다.

GIF는 확인을 위해 한 페이지 6.4초씩 두 페이지, 총 12.8초로 반복한다. GIF의 반복과 다음 페이지 자동 전환은 검토용이다. 실제 도입 화면은 입장 연출 1회 뒤 아이콘으로 다음/건너뛰기를 선택하고, 페이지 자동 넘김은 하지 않는 명세다. 이번 GIF에는 소리나 버튼을 넣지 않았다.

## 파일과 재생성

- `page-01-generated.png`, `page-02-generated.png`: 글자 없는 Sunburst 원화.
- `page-01-board.png`, `page-02-board.png`, `two-page-board.jpg`: 네 컷이 붙은 최종 상태.
- `stamp-preview.gif`: 실제 프레임을 인코딩한 393×852 모션 시안.
- `page-01-motion-frames.jpg`, `page-02-motion-frames.jpg`: 등장 과정과 정착 후 유지 상태 표본.
- `render_preview.py`: 기존 Pillow만 사용하는 재생성 스크립트. 게임 코드를 호출하거나 변경하지 않으며 함수 정의를 추가하지 않는다.
- `motion-check.json`: 매 시각의 누적 표시 컷·GIF 길이 등 검사 기록.
- `generation.json`, 프롬프트와 참조 PNG: 실제 모델 입력·사용량.
- `../../../resources/story/cat-liquid-intro.json`: 무문자 설정, 컷 이미지와 모션 타이밍. 아직 게임에서 읽지 않는 제작 명세다.
- `../asset-manifest.json`: 현재 WebP 10개의 크기·용량·SHA-256. 배포용 WebP를 이번 원화로 교체했다.

프로젝트 루트에서 `python3 artifacts/cat-liquid-comic/revision-03/render_preview.py`로 WebP·최종 상태·GIF·검사 기록을 다시 만들 수 있다. 모션 값은 위 스토리 JSON이 기준이며 UI binding/event 키가 아니다.

## 확인 범위

원화 두 장과 네 컷 최종 배치, 연속 표본 이미지를 직접 열었다. 게임 얼굴/나무 형태의 반영, 글자 없는 서사, 연구실·박사·세 고양이의 연속성, 순차 누적 표시를 확인했다. 자동 검사에서는 컷 표시 순서, 200ms 후 정착, 마지막 두 표본의 픽셀 일치, GIF 디코드 길이 12,800ms, 이미지 경로·해시를 확인한다. 실제 게임 브라우저에서 재생했다고 보고하지 않는다. 그림체와 타격감에 대한 최종 선호는 사용자 확인 대상이다.
