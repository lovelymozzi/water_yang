# 괴짜 어린 박사 — 배합 사고와 고양이 세계

revision13 중간 작업 기록. **현재 게임은 [revision14](../revision-14/README.md)**이며, 못된 인상이라는 사용자 피드백에 따라 박사의 표정을 다시 수정했다. 아래는 당시 적용 상태다. 흰 머리·고양이 귀 머리띠·투명한 빨간 동그란 뿔테·흰 가운은 유지하고, 사용자가 준 18:19:40 이미지에서는 비대칭 눈썹·반쯤 내리뜬 눈·장난스러운 입꼬리라는 표정 방향만 참고했다. 기존의 부드러운 입체 게임 그림체를 유지했다.

## 최종 이야기

1. 실제 연구실에서 용기에 몸을 맞춘 고양이를 관찰하며 노트 기록. 색색 액체 플라스크·시험관·연구 자료·고양이 골격/척추 해부도 칠판이 보인다. 가정집 소파/쿠션은 없다.
2. 박사가 자신만만하게 플라스크 액체를 배합한다.
3. 배합 실패로 청록/보라 마법빛과 연기가 터지고, 이어진 빛이 바닥 차원문을 열어 박사를 빨아들인다. 스위치와 전선으로 작동시키던 원인은 제거했다.
4. 낯선 숲 세계에 도착해 문 옆에 주저앉아 머리에 손을 대고 어리둥절해한다.
5. 현지 초록 고양이를 두 손으로 가슴 아래에서 받쳐 들자 몸이 중력 때문에 길게 늘어진다. 길이를 재거나 몸 양끝을 잡아당기는 실험 장면이 아니다. 고양이는 반쯤 감긴 눈과 힘이 빠진 입매의 나른한 표정을 유지한다.
6. 같은 색 문 너머에서 플라스크와 칠판이 있는 인간계 연구실을 확인한다.
7. 고양이를 각자 같은 색 바닥 차원문으로 안내한다.
8. 계획대로 들어가는 고양이에게 장난기 있는 미소로 배웅한다.

들어 올린 고양이는 앞발2·뒷발2·꼬리1이 몸에 연결돼 있고, 박사는 상부 가슴만 받친다. 얼굴에 눈물/겁먹은 눈/벌어진 비명 입/납작하게 접힌 귀는 없다. 나른한 얼굴은 실제 게임 고양이 참조를 포함한 `relocated-lift-input.png`를 입력으로 사용했다. 과장된 긴 몸통은 만화적 표현이며 실제 골격 비율과 동일하다고 주장하지 않는다.
