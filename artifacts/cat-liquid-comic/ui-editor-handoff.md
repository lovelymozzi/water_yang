# 고양이 액체 이야기 — UI Editor 연결 명세

2026-11-15. 만화 2페이지와 개별 8컷, 별도 한국어 대사를 제작했다. 현재 게임 실행 흐름은 수정하지 않았다. `resources/story/cat-liquid-intro.json`은 제작 명세이며 아직 런타임에서 읽지 않는다.

## UI Editor에 추가할 내용

- 기본 캔버스는 기존 게임과 같은 393×852. 4컷을 왼쪽 위 → 오른쪽 위 → 왼쪽 아래 → 오른쪽 아래 순서로 읽는 2열×2행 구조다.
- 이야기 씬 2개를 제작한다. 제안 이름은 `StoryIntro01`, `StoryIntro02`이며, 생성된 실제 sceneUuid로 배선한다.
- 제목·부제·컷별 대사는 이미지에 굽지 않고 각각 텍스트 레이어로 둔다. 대사와 줄바꿈은 위 JSON을 사용한다. 각 컷의 번호는 화면 독서 순서를 알려주는 별도 텍스트다.
- 이미지 레이어는 `src/assets/story_cat_liquid_panel_01.webp`부터 `_08.webp`를 각각 사용한다. 완성 4컷 원화는 `story_cat_liquid_page_01.webp`, `_02.webp`로도 제공한다. 둘 중 한 방식을 선택하고 중복 로드하지 않는다.
- 사진 영역은 가로세로 비율을 보존한다. 각 컷 원화는 500×756이다. 잘라내는 cover 대신 contain으로 배치한다. 캐릭터의 귀·발이 잘리지 않도록 한다.
- 버튼은 기존 `home_btn_stage_normal.png` 리소스를 사용한다. 첫 페이지의 `다음`, 마지막 페이지의 `모험 시작`, 각 페이지 상단의 `건너뛰기`가 필요하다. 이벤트 이름·stableId는 UI Editor가 publish한 결과를 사용한다. 게임 코드에서 먼저 임의로 발명하지 않는다.
- UI 글꼴은 기존 씬의 `"Lilita One", cursive` 설정과 기존 시스템 한글 폴백을 유지한다. 시안 PNG의 한국어는 macOS 폴백인 Apple SD Gothic Neo로 합성했다. 새로운 웹폰트는 추가하지 않았다.
- 393×852 시안 기준 이미지 영역은 x=16/203, y=140/430, w=174, h=228이다. 각 대사는 이미지 밑 두 줄이며 제목·진행 페이지 표시·버튼과 겹치지 않는다. 실제 에디터 배치에서는 시안의 여백을 참고한다.

## 흐름

기존 스플래시 로딩을 완료한 뒤 분기한다. 조건의 의미는 아래와 같으며, UI Editor의 실제 분기 키와 publish 버튼 이벤트가 확보되면 기존 호스트의 조건·scene:enter 훅에 연결한다.

1. 이 브라우저에서 이야기를 끝까지 보거나 건너뛴 이력이 없으면 1페이지를 연다.
2. `다음`은 2페이지를 연다. 시간에 따라 자동으로 넘기지 않는다.
3. `모험 시작`은 완료 표시를 저장하고 기존 로비로 이동한다. 스테이지를 자동 시작하거나 하트를 소비하지 않는다.
4. 어느 페이지에서든 `건너뛰기`를 누르면 완료 표시를 저장하고 기존 로비로 이동한다.
5. 이후 입장에서는 기존 스플래시 → 로비 경로를 사용한다.
6. 이미지가 먼저 디코드된 뒤 페이지를 공개한다. 기존 `scene:enter.waitUntil`과 공개 전환 API를 사용한다. 소스·계약·흐름 변경 뒤 캐시 버전도 확인한다.

게임 이동·카메라·퍼즐 배치·타이머·재화 규칙을 바꾸지 않는다. 완료 표시는 스테이지 진행도와 분리하고 기존 저장 프리픽스를 사용한다.

## 현재 제약과 필요한 조치

`SCENES.md`와 현재 publish 산출물에는 이야기 씬·다음·건너뛰기 이벤트가 없다. `publish-report.json`의 errors는 0개이고 `scene-flow-changes.json`은 없다.

AGENTS.md와 `.codex/skills/ui-editor-game/SKILL.md` §1은 `*.contract.json`, `scenes-index.json`, `scene-flow.json`을 읽기 전용으로 지정한다. 같은 스킬 §0은 “SCENES.md 에 없는 이벤트/키가 필요 — 임의 생성 금지, ui-editor 에서 추가해 달라고 요청”하도록 규정한다.

따라서 위 씬·버튼·흐름을 UI Editor에서 추가해 publish하거나, 이번 이야기 도입 작업에 한해 새 씬·이벤트·흐름의 직접 생성 예외를 사용자에게 승인받은 뒤 실제 게임 연결을 진행해야 한다. 이전 승인은 팝업 배경 수정에 한정되어 있다. 임시 HTML 팝업이나 수동 씬 전환으로 우회하지 않았다.

## 확인 범위

- 모델에 실제 로비·직선/굽힌 고양이·차원문 캡처를 이미지 참조로 제공했다. 2페이지에는 1페이지도 함께 제공해 캐릭터 일관성을 유도했다.
- 생성 원본을 직접 열어 4컷 구성, 세 고양이의 색·얼굴, 용기 장면, 길쭉한 몸과 L자 굽힘, 같은 색 차원문을 확인했다.
- 이 그림은 원본 메시·셰이더의 재렌더링이 아니다. 현재 게임과 픽셀 단위로 동일한 그림체라고 판정하지 않는다. 최종 그림체·대사 선호와 실제 UI 표시는 사용자 확인 대상이다.
- `page-01-preview.png`, `page-02-preview.png`는 문구·배치를 확인하기 위한 정적 시안이다. 버튼은 클릭되지 않으며, 게임 연결 완료를 뜻하지 않는다.
