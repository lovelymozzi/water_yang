# 둥근 안경의 새 연구자와 용기 모양 고양이

2026-11-15. 새 연구자 디자인과 사용자 고양이 사진을 만화 8컷에 반영했다. 최신 사용자 지시는 **동그란 안경 착용, 머리 위 고글 제외**, 용기에 꼭 들어찬 고양이 포즈, `next` 오른쪽의 작은 오른쪽 삼각형이다.

## 디자인과 사진 반영

짧은 짙은 보라색 곱슬머리, 둥근 얼굴과 굵은 눈썹, 보통 크기의 원형 안경, 청록 작업복, 겨자색 공구 조끼, 장화, 짧고 통통한 성인 체형을 새로 만들었다. 과거의 흰 머리·고글·아이보리 코트·주황 스카프 디자인을 사용하지 않았다. `researcher-design.png`의 세 시점 디자인을 먼저 생성·파일 검토했고, 그 디자인과 기존 게임 고양이·배경, 사용자가 새로 제공한 고양이 사진만 합쳐 `comic-design-and-container-reference.png`를 만들었다. 기존 프랜차이즈 캐릭터 이미지는 새 생성에 입력하지 않았다.

사진에서 원형 병/어항을 채운 둥근 웅크림, 사각 투명 통을 채운 긴 loaf형 몸과 가장자리에 눌린 볼, 긴 원통을 채우는 접힌 몸을 참고했다. 스크린샷 글자·사이트 UI는 원화에 넣지 않도록 요청했다. 용기 안에서는 팔다리를 접어 가리고, 네 다리가 어깨·골반에 붙은 구조를 유지하며 유리 벽을 관통하지 않도록 점검했다. 마지막 컷의 고양이는 바닥 차원문으로 내려가므로 앞다리는 가리고 뒷발 한 쌍과 꼬리가 보인다. 모든 차원문은 바닥에 놓인 수평 구멍이다.

6컷의 차원문 안 연구실 고양이가 초기에는 앞 장면과 달라 한 번 보정했다. 크림색 둥근 병 고양이와 주황색 투명 사각 통 고양이로 통일했다. 최초 5~6컷 원화는 `pair-03-initial-generated.png`에 남기고, 최종은 `pair-03-generated.png`다. 그 요청의 최초 응답 JSON image 경로는 생성 당시 경로다. `art-review.json`에 실제 파일 관찰을 남겼다.

## 적용과 next ▶

이야기 revision10, 새 `story_cat_liquid_shapes_*` 파일을 UI Editor 원본 두 씬과 실행 contract 두 씬에 연결했다. 대사 없는 세로 4컷×2페이지와 누적 등장, skip/next, 배경·기존 5개 흐름 엣지는 유지한다. 새로운 이벤트는 만들지 않았다.

`next`는 기존 버튼 안에서 왼쪽으로 9px 옮기고, 같은 버튼의 두 번째 텍스트 슬롯에 14px `▶`를 오른쪽에 추가했다. 삼각형은 같은 80×44 터치 영역 안에 있으며 published renderer의 텍스트는 pointer-events:none이므로 삼각형 터치도 원래 next 버튼으로 간다. 별도 클릭 이벤트·레이어를 중복 구현하지 않았다. 실제 버튼의 aria-label은 기존 next다. 미리보기 생성기에도 작은 삼각형을 반영했다. 하단에는 skip과 next ▶만 보인다.

JS/CSS는 변경이 없어 `cat-liquid-v10` 유지. JSON은 기존의 명시적 새로고침 캐시 수정으로 최신 값을 읽으며 새 카드 경로도 이전 캐시와 구분된다. 과거 실행 캐시 오류 수정, 게임플레이·카메라·저장/완료 키는 유지했다. SceneRenderer/매니저/Godot 본체는 수정하지 않았다.
