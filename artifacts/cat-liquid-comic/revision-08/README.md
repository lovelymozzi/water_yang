# 무대사 만화와 세로 화면 확장

2026-11-15. 다국어 처리를 고려해 이야기의 대사·대사창·타이핑·텍스트 바인딩을 전부 제거했다. 진행 글자는 하단 왼쪽 `skip`, 오른쪽 `next`뿐이다. 앞서 허용된 이번 만화의 직접 적용 범위에서 UI Editor 원본, 실행용 계약, 흐름과 훅을 함께 변경했다. 게임플레이나 카메라는 수정하지 않았다.

## 그림과 배치

기존 괴짜 연구자와 고양이를 참조해 Sunburst 스킬의 기본 Flava 스크립트로 1024×1024 원화 4장을 만들었다. 각 원화에 약 2:1 구도의 두 컷을 담아 총 8컷이며, 실제 흰 여백을 측정해 분리했다. 인물을 세로로 늘리는 대신 구도를 다시 그렸다. 글자·대사·설명칸을 생성하지 않도록 요청했고 원화를 열어 확인했다. 연구 노트에는 컵/상자 고양이 도형만 있다.

학자·컵 고양이 조사 → 장치 사고 → 숲의 컵/상자 고양이 → 노트 기록 → 초록 고양이와 초록 차원문 접촉 → 연구실로 열린 문 → 소파를 보는 고양이 → 색별 차원문으로 출발 순서다. 표정·행동·반복된 물건·색 대응으로 이야기를 전달한다. 등장 박사와 차원문은 창작이며, 실제 논문 정보는 이야기 JSON에 보존했다.

393×852 기준, 각 카드의 표시 크기는 385×192, 왼쪽 여백 4px, 위쪽 좌표는 4/200/396/592다. 기존 372×145보다 크게 배치했다. 네 컷 완성 시 카드 영역은 화면 면적의 약 88.3%, 하단 끝은 y784다. 남은 하단에는 y800~844의 80×44 터치 영역 두 개를 두었다. skip x16, next x297이며 버튼은 그림과 겹치지 않는다. 사선 검은 프레임과 흰 가장자리, 상점 배경은 유지한다.

## 진행

첫 컷은 240ms 후 기존 스탬프 모션으로 나타난다. `next`를 한 번 누를 때마다 다음 컷이 추가되고 이전 컷은 남는다. 네 번째 컷에서는 `story.pageComplete` 문서 엣지로 다음 페이지, 여덟 번째 컷에서는 완료 저장 후 `story.finish`로 로비에 간다. 아무 입력 없이 다음 컷으로 진행하지 않는다.

`skip`은 두 페이지의 어느 컷에서나, 첫 컷이 나오기 전에도 완료 저장 후 기존 로비 홈 탭으로 이동한다. `story.complete` 조건은 진행 중 상태가 있을 때 한 번만 완료 처리를 하므로 연타가 중복 저장을 만들지 않는다. 첫 입장 분기 1개, 페이지 문서 엣지 2개, skip 엣지 2개로 총 5개다. 두 흐름 파일과 `SCENES.md`가 같은 이벤트를 선언한다.

기존 seen 키, `?story=replay`, 움직임 줄이기 설정을 유지한다. 언어별 대사 데이터·글자 단위 타이핑 루프는 없다. 초기 등장 대기 rAF만 사용하며 첫 컷 공개/건너뛰기/씬 이탈 시 종료한다. CSS/JS는 `cat-liquid-v9`, 새 에셋은 `story_cat_liquid_full_*`로 이전 캐시와 구분한다.

## 확인

원화 네 장과 `two-page-board.jpg` 배치 시안을 열어 장면·잘림·하단 두 글자·대사창 제거를 확인했다. `asset-check.json`에는 분리 좌표·해시·크기·대사 필드 부재·면적 비율을 기록했다. 페이지별 PNG/JPG와 `panel-preview.gif`는 Pillow 시안이며 실제 게임 캡처가 아니다. GIF만 시연을 위해 자동 진행한다. 실제 게임의 시각/브라우저 확인은 프로젝트 규칙에 따라 사용자가 수행한다.

`story_intro_check.mjs`는 실제 FlowDriver와 렌더러/DOM 대역으로 무대사 계약, 하단 skip/next, 초기 대기, next 즉시 진행, 두 문서 엣지, 두 페이지 skip, 첫 컷 전 skip, 키보드, 연타 1회 저장, 캐시 재입장/재접속/다시보기를 확인했고 통과했다. `splash_cache_check.mjs`, `ui_bare_asset_paths_check.mjs`도 통과했다. localhost의 HTML/JS/CSS/데이터/흐름/계약/카드/타격선 16개 응답이 작업 폴더와 일치한다. 기존 publish 보고서는 errors 0개/warnings 8개이며 이번 검사 결과로 덮어쓰지 않았다.
