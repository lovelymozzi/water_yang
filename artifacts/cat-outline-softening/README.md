# 인게임 고양이 외곽선 완화

2026-11-15. 사용자가 인게임 선은 너무 짙고 로비는 괜찮다고 구분해 요청했다. 로비의 기존 스타일은 유지한다.

- 나무 인스턴스는 잎과 가까운 녹색 `(0.3122174, 0.43458626, 0.24556792)`·모델 단위 폭 `0.005`를 사용한다. 모델 배율이 달라 수치를 그대로 복사하지 않고, 고양이도 얇은 선과 몸 색에 가까운 색을 사용하도록 조정했다.
- 인게임의 선 폭/깊이 바이어스 배율은 `1.65 → 0.75`로 바꿨다(직전의 약 45%). 잉크 RGB의 추가 0.82배 어둡힘을 제거하고 몸 틴트의 선형 RGB를 25% 섞는다.
- `soft_outline_enabled`는 `_floating_water_outline`의 반대값으로 두 스킨 서피스에 설정한다. 로비에서는 false로 바뀌어 기존 폭·색 수식이 그대로 실행된다. 본체와 같은 스키닝·흡입 처리를 사용한다.
- `comparison.png`는 직전 결과(왼쪽)와 이번 결과(오른쪽)의 같은 U/L 자세를 2배 최근접 확대했다. 직전 전체 화면은 `../cat-storybook-review/after/2_tight_bends.png`, 이번 전체 화면은 `after.png`다. 배경에는 기존 미커밋 지형 작업이 포함되어 있다.
- Godot `4.7.2.stable.official.ed1daf0bf`, 실제 Compatibility/OpenGL 렌더에서 직선·L·S·U와 이동 17표본을 확인했다. 캡처 실행은 `tests/capture_length.tscn`. 렌더 종료에는 이전에도 발생하던 shader RID 해제 경고가 남는다.
- `tests/length_check.tscn`은 기존 몸 길이·굽힘 검사와 두 서피스의 인게임 완화/로비 해제를 검사해 `LENGTH CHECK: PASS`로 통과했다. 웹 release 내보내기도 성공했다. 사용자가 열어 둔 인게임 탭은 재로드하지 않았다. 실제 색감의 최종 선호는 사용자 확인 대상이다.
